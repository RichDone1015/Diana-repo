# AI 报表分析与 Validation 校验规则平台

## 使用方式

直接用浏览器打开 `index.html`。页面无需安装依赖，也不依赖外部网络资源。

- 左侧导航可进入全部业务模块。
- 顶部“中 / EN”开关支持全局中英文切换，语言选择会在页面跳转与刷新后保留。
- 默认展示英文界面；使用 `?lang=en#reporting-detail` 可强制打开英文案例，使用 `?lang=zh` 可打开中文版本。
- 右上角用户菜单可切换“管理员 / 普通用户”，用于验证审批控制中心与管理员模块卡的权限显隐。
- 右下角“状态演示”可切换当前页面的正常、空态和失败态；截图采集时会自动隐藏该控件。
- Reporting 和 Validation 的清单、配置、详情、抽屉、弹窗、审批确认和生成进度均可点击体验。
- Reporting 详情采用上传表样驱动的 Web Excel 展示；右键或双击有内容标记的单元格可查看 BRD / FSD、SQL 和伪代码。
- 配置页支持上传新版表样；详情页和版本抽屉支持按表样版本、逻辑版本、制度批次查询历史版本与逻辑差异。

## 当前案例

当前案例基于 `20260331_withAI.xlsx`：

- 主报表：`CNHSBC006A-20260331`
- G01 资产负债项目统计表附注
- 第Ⅱ部分：贷款质量五级分类情况简表
- 5 个工作表：G01 主报表、填报项清单、StarRocks 取数映射、标记说明、本期 SQL 快照
- 11 个真实填报项及对应报送值、复核状态、StarRocks 来源与计算逻辑
- 主报表科目、字段标题、取数逻辑、标记说明与 SQL 快照均已提供英文展示
